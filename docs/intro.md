# Kootenay Lightweb

Planning and reference material for the **Kootenay Lightweb Community Services Cooperative** — a registered co-op running production infrastructure on the *Liberty* 4-node Proxmox/Ceph/Kubernetes cluster.

## What's in here

- **[Background](./background)** — working session notes, philosophical frame, and the strategic ask. Start here.
- **[Technical Stack](./technical-stack)** — the production stack on Liberty today, the application layer in flight, and integration points across the ecosystem.
- **[Uluntu and the Roadmap](./uluntu-roadmap-fit)** — review of the Uluntu repo and where it fits as the Lightweb's magnetic core.
- **Research**
  - [LLM Hosting Cost & Infrastructure](./research/llm-hosting-cost-infrastructure) — co-op-owned LLM serving economics for the ~144 → ~1,000 user horizon.

## Strategic frame

Every decision loops back to: *does this strengthen offline trust and local resilience, or pull people deeper into screens?*

- Federated scale: individual → group → community → regional → global, with local control at every layer.
- "Good AI": community-owned, opt-in, transparent, renewable-powered, running on co-op hardware. Opting out of AI is fully supported.
- Replication-ready: what's built should be a template other bioregions can adopt.
